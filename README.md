# 🏷️ Gerador de Etiquetas Automatizadas

Pequeno sistema desenvolvido para facilitar o preenchimento de produtos em planilhas.

A aplicação utiliza OCR para ler informações de etiquetas a partir de imagens `.jpeg` e transformar os dados em um arquivo `.csv`.

## Como funciona

1. Selecione uma ou várias fotos das etiquetas.
2. O sistema identifica os dados da imagem utilizando OCR.
3. Clique em **Baixar**.
4. Um arquivo `.csv` é gerado com todos os produtos.

- Item
- Nome do item
- Código
- Validade
- Quantidade
- Fornecedor
